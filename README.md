### Recent work

Most of my production work lives in private client or company repositories. Short case
studies:

- **ETIS: multi-tenant school platform** (C#/.NET DDD + CQRS, React 19, AWS ECS Fargate,
  CloudFormation). White-labelled SaaS for DRC secondary schools with student, parent, teacher and
  admin consoles in French and English, TOTP MFA, tenant isolation, and offline-capable attendance
  and grade entry.
- **CorePay DRC: payroll & compliance** (.NET, GCP, Terraform). Cloud Run API and compliance
  engine, Cloud SQL with PostgreSQL row-level security for tenant isolation, a transactional outbox
  feeding Pub/Sub, and a daily Cloud Run Job that collects central-bank exchange rates.
- **SalonHub: multi-tenant salon SaaS** (Kotlin/Spring Boot, Next.js, GCP, Terraform). Keyless
  GitLab CI/CD via Workload Identity Federation, a global HTTPS load balancer in front of Cloud Run,
  and native iOS apps.
- **Mondmorrea: e-commerce platform** (Spring Boot, Next.js, GCP). PayFast and PayPal payments,
  Resilience4j circuit breakers, RabbitMQ events, and ShedLock to stop duplicate scheduled jobs.
- **Mzansi Fashion: microservices e-commerce** (Django + 11 FastAPI services, RabbitMQ, Keycloak,
  Traefik). A three-tier private-network topology with Prometheus, Grafana and Loki monitoring.
